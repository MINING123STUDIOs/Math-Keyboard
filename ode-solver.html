ODE Solver

Non-Linear Ordinary Differential Equation Solver API

A Python API for simulating physical systems described by non-linear ordinary differential equations. Supports multiple numerical integration methods with configurable step sizes, precision, and parallel execution.

Features

  • Explicit & implicit Euler — simple first-order methods for fast prototyping
  • Runge–Kutta — orders 2 and 4 for better accuracy
  • Gauss–Legendre — implicit methods (orders 2, 4, 6) for stiff systems
  • Configurable constants — physics parameters via config.ini
  • Parallel support — run multiple simulations concurrently
  • Simple API — define an ODE function, call simulate()

Quick Start

# Copy these files into your project:
#   sim_API.py, math_API.py, special_API.py, config.ini

from sim_API import simulate

def ode(t, x):
    return -x  # dx/dt = -x

result = simulate(ode, t=10.0, x0=1.0, method='rk4', dt=0.01)
print(result)
