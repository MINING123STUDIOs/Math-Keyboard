Web Cruncher
Multi-threaded mathematical constant digit calculator inspired by y-cruncher. Computes digits of 38 constants using Web Workers, streaming output, and BigInt arithmetic.

Algorithms: Chudnovsky (π), Taylor (e), Newton (√n), AGM (Γ, lemniscate), Euler-Maclaurin (ζ), Brent-McMillan (γ), Machin (π alt), hypergeometric (ζ(3)), alternating series (ln, Catalan), fixed-point (Ω, Dottie).
