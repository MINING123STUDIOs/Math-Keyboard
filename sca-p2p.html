🧭 How it works

1. Create a room or join one. One person creates a room and gets an invite link. The other opens that link and joins. No account, no sign-up, nothing.

2. Exchange the answer link. When someone joins, they get an answer link. Send it back to the host through any channel: email, chat, phone call, a note on paper, anything. The host pastes it and clicks "Accept Answer."

3. Chat. Once connected, all messages are end-to-end encrypted. You can also send files (up to 512 MB). They are chunked, encrypted, and reassembled on the other end.

📨 This tool connects directly to your friend's browser. There is no server in the middle storing your messages. The only server involved is a STUN server (run by Google) which helps your browsers find each other. It never sees your messages or metadata.

🔒 Double encryption. WebRTC already encrypts the transport layer (DTLS). On top of that, every message is individually encrypted with a Double Ratchet session (ECDH P-256 + HKDF + AES-256-GCM), the same construction used by Signal. Even if one message key were ever exposed, it wouldn't expose past or future messages.

🔑 Every message uses a fresh key. The two of you re-key on every exchange, so forward security is maintained throughout the conversation.

⚠️ Refreshing or closing this page erases everything including your keys, your session, the chat history (unless saved in this browser), all of it. There's no account and no cloud backup. Your browser will ask you to confirm before leaving the page as a safety net.

🔒 For best possible security, download the source files to your device and run the tool offline after verifying the program. This is also highly recommended for compatibility reasons.

🌐 Password-protected rooms. If you set a password when creating a room, the invite link is encrypted with it (PBKDF2 + AES-256-GCM). Only someone with the password can join. But the password is never sent over the network.

📎 File transfers are encrypted the same way as text messages. Files are split into 64 KB chunks, each individually encrypted, and reassembled on the receiving end. Max file size is 512 MB.

👥 Group chat is supported. Each additional person joins the same way (create room → share invite → exchange answers). Every pair of peers has an independent encrypted session.
