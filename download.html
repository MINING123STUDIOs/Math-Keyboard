What's Inside

Math & Computation

  • Math Keyboard — ~3,700 math symbols with search, copy and download
  • 1-Bit Calculator — Boolean logic on single bits A and B
  • Numerical Analysis — arbitrary-precision calculator, calculus and more, up to 100,000 digits
  • Web Cruncher — multi-threaded mathematical constant digit calculator using Web Workers
  • sPIgot — digits of pi streaming across the screen from a spigot algorithm
  • Logic Evaluator — Boolean expression evaluator with truth tables and simplification

Language & Logic

  • Colorless Green Ideas — Chomsky-style sentence generator with syntax and review modes
  • Library of Babel — find the exact book whose first line is your words
  • TM0 Visualizer — toolchain for the TM0 tiny Turing-machine dialect

Editor & Dev

  • Clean Editor — fast, minimal code editor with syntax styling and light/dark theme

Creative & Play

  • Cell Battles — probabilistic cellular automaton where ROCK and PAPER compete
  • Elementary CA Explorer — all 256 elementary cellular automaton rules
  • Kuvina Fractals — totalistic cellular automaton with N states
  • L-System Fractal Garden — L-system fractal explorer with 13 presets
  • Hilbert Rainbow Curve — space-filling Hilbert curve with rainbow gradient
  • CPU Burner — configurable stress tests with live performance monitoring

Worlds & Physics

  • Liquid Lab — interactive Navier-Stokes flow field with direction, speed, curl, pressure and heat views
  • Landscape Explorer — infinite procedural world: mazes, caves, biomes and more
  • P2P Chat — encrypted peer-to-peer messaging with WebRTC
  • Secure Channel — end-to-end encrypted messaging with Double Ratchet key exchange
